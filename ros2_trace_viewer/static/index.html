How are these values calculated?

Durations are summed across full executions inside the selected interval. Share compares that sum with all selected callback durations. Overlapping callbacks can run simultaneously; these values describe wall-clock callback durations, not CPU use. Boundary-crossing executions are excluded from aggregates.
